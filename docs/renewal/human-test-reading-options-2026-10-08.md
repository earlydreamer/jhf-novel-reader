# 자동 시작 옵션과 문단 재번역 휴먼 테스트

Black Shark2의 **나로우 리더 · 테스트**에 소스 `90c0ec692b868a9a7057aa66ab2ea5cbb2b16638`를 설치했다. 최종 업데이트 직전 저장본8개와 설정은 그대로 보존했다. 처음 업데이트 기준 저장본7개도 모두 유지된다. [설계](local-streaming-design.md), [기기 결과](evidence/reading-options-2026-10-08/device-results.json).

## 직접 확인할 흐름

1. **설정 → 저장본이 없으면 자동 번역 시작**으로 조절한다. 기본은 켜짐이다. 켜면 목차나 다음 화에서 저장본 없는 회차를 열 때 자동으로 번역하고, 끄면 ‘이 화 번역’ 버튼으로 시작한다. 저장본을 열 때는 모델 요청을 보내지 않는다. 선택은 앱 재시작 후에도 유지된다.
2. 완료 후 같은 본문에서 **목차·이전 화·다음 화·원문 확인·글자 크기**를 바로 사용한다. ‘저장본으로 읽기’를 추가로 누르지 않아도 된다. 읽기 영역과 스크롤을 유지한다.
3. **설정 → 실패 문단 자동 재시도**는 별도 옵션이다. 기본 켜짐이고, 검증에 실패한 문단만 한 번 더 요청한다. 정상 문단은 재생성하지 않는다. ID 계약 전체가 깨지면 그 청크 전체가 실패 대상이다. 통신 결과 불명은 자동으로 재전송하지 않는다.
4. 독서 화면 아래 **실패 문단 다시 번역** 또는 **문단을 골라 다시 번역**을 사용한다. 문단 하나나 실패한 문단 전체만 요청하고 새 저장본을 만든다. 이전 저장본과 선택하지 않은 문단은 보존한다. 재번역도 실패하면 기존 내용을 남긴다. 저장만 실패하면 모델 요청 없이 저장만 재시도한다.

수동으로 다시 보낸 문단은 이번 모델 응답에서도 검증에 실패했다. **수동 요청 기능과 데이터 보존은 확인했지만 해당 문단의 번역 복구를 성공으로 판정하지 않는다.** 자동 재시도가 성공한 회차와 이 수동 실패 문단을 구분한다.

문단 재번역의 요청 결과 불명 상황은 **테스트용 브리지 거부 1회**로 주입했다. 실제 네트워크 단절은 아니다. 자동 재전송0이며 사용자가 명시적으로 재시도하면 실제 모델 POST1로 같은1문단만 보낸다. [응답 메타데이터와 재시도 범위](evidence/reading-options-2026-10-08/wire-summary.json).
