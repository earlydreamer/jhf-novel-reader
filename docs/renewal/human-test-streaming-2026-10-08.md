# 로컬 스트리밍 휴먼 테스트

Black Shark 2의 **나로우 리더 · 테스트**에 소스 `aeb906b1a53b45b858bad32097d53e6e09f913ba`를 설치했다. 테스트 패키지 `app.narou.reader.proof80`를 데이터 유지 업데이트했고, 기존 저장본 3개와 설정을 보존했다. 생산 앱의 10파일·설정·설치 APK는 바이트까지 유지했다. [설계](local-streaming-design.md), [기기 지표](evidence/local-streaming-2026-10-08/device-results.json), [응답/저장 대조](evidence/local-streaming-2026-10-08/wire-verification.json).

## 직접 확인할 흐름

1. 현재 열린 실제 저장본을 읽고 **목차 → 아직 저장하지 않은 회차 → 이 화 번역**을 누른다. 새 기본인 **읽으며 번역 (실시간)**은 도착한 문장을 읽기 영역에 바로 표시한다.
2. 첫 문단이 나오면 읽고 스크롤한다. 뒤 문단이 늘어나는 동안 읽던 위치가 유지되는지 본다. 한 화를 저장한 후에도 현재 읽기 영역은 유지되며, **저장본으로 읽기**를 누르면 해당 위치를 완성 리더로 이어받는다.
3. **설정 → 로컬 번역 방식 → 기존 묶음 번역**을 선택하면 이전 경로를 사용한다. 선택은 재시작 후에도 유지된다. 실기 검증 후에는 실시간 방식을 다시 선택해 뒀다.
4. 작품 용어집에서 확정한 이름을 번역 중 확인한다. 확정 용어는 임시 토큰으로 가린 뒤 복원한다. **이전 이야기 요약**은 이름을 빼고 최대400자로 직접 입력하는 선택 메모다. 자동 요약 생성은 이 버전에서 실행하지 않는다.
5. 중단하면 미리보기는 완성 저장본으로 저장되지 않는다. 서버 처리가 끝났는지 모르는 요청을 자동으로 다시 보내지 않는다. 문단 ID·가나·잠근 표기 검사에 실패하면 해당 청크를 한 번 다시 생성하고, 계속 실패한 줄은 **[번역 실패 · 원문]**으로 남긴다.

## 실제 모델 측정

설정된 E4B를 바꾸지 않고 실제 원문을 새 경로로 번역했다. 아래 시간은 동일 요청의 기기 시계를 기준으로 모델 POST 시작부터 측정했다. 첫 표시는 읽기 영역 DOM에서 텍스트가 나타난 시점이며 사람이 직접 눈으로 잰 반응 시간은 아니다.

## 검증 범위

- 로컬 전체62파일·763테스트, 타입·린트·포맷·웹 빌드 PASS. SSE 프레임 분할, ID/줄 합치기, 용어 누락, 한 번 재생성, 원문 실패 표시, 8K 예산, 직전 문맥 삭제, 저장만 재시도, 기존 방식 유지, 스크롤 보존을 포함한다.
- 생산 debug/계측 APK 빌드·출처·보안 감사 PASS. 새 `ModelStreamPlugin`이 DEX에 포함되고 `MainActivity`에서 등록됨을 확인했다. 테스트 APK와 생산 APK는 assets16개 및 DEX가 같다. [자산 대조](evidence/local-streaming-2026-10-08/assets-verification.json), [설치/원본 보존](evidence/local-streaming-2026-10-08/preservation.json).
- 이 실제 회차에서는 직전 원문/번역 한 쌍이 입력 예산을 넘어 **6개 요청 모두 히스토리를 제외**했다. 등장한 사용자 확정 용어가 없어 마스킹도 사용되지 않았다. 이 두 동작은 자동 테스트에서 검증했으며 이 회차의 실측을 실제 마스킹·히스토리 전달 성공으로 확대하지 않는다.
- 앱의 입력+출력 예약 상한은8192다. 서버의 기존16384 설정·모델·OS를 변경하지 않았다. 따라서 이 결과가 RTX3070Ti8GB에서의 VRAM 적합성을 증명하지 않는다.
- 총시간 개선이나 의미·말투 합격을 주장하지 않는다. 이전 방식과 다른 회차를 측정했다. #72 OPEN / PR81 Draft를 유지한다.

직접 설치할 APK는 private 작업 폴더의 `narou-reader-human-test-aeb906b.apk`이며 SHA-256은 `3e401e68c13e628d6ea97303acf06e8cd99d31e76df313a5df3fc91849c66e53`다. 전문·프롬프트·사설주소는 공개 기록에 넣지 않았다. 시험 훅 없는 새 프로세스로 완성 저장본 독서 화면을 열었고 임시ADB forward를 제거했다. 이전 범위 스캔·목차·연결 복원 검증은 [기존 안내](human-test-glossary-2026-10-08.md)에 남아 있다.
