# 작품 제목과 회차 제목 번역·편집

작품 제목과 소제목(회차 제목)을 본문과 별도로 번역·저장하고 목차·독서 화면·최근 읽기에 같은 저장값을 사용한다. 원문 제목과 기존 본문 저장본은 보존한다. 설치 소스는 `7f87ff08ae17780f26339fb36db6e3cb12f0ad0d`이며 후속 보고 커밋과 구분한다.

## 직접 사용할 기능

- 작품 목차의 작품 제목 바로 아래 **제목 번역 / 제목 재번역**, **제목 수정**을 사용한다.
- 각 목차 회차 바로 아래에도 같은 버튼이 있다. 독서 화면에서는 회차 제목 바로 아래에서 사용한다. 접힌 메뉴나 본문 아래로 숨기지 않았다.
- 제목 수정은 원제를 보여 주고 번역문을 직접 입력해 저장한다. 수정은 모델 연결 없이 가능하다. 저장 실패 시 입력을 남긴다.
- **미번역 목차 제목 번역**은 저장값이 없는 제목만 채운다. 직접 수정한 제목을 덮어쓰지 않는다. 특정 제목의 재번역 버튼은 그 제목만 명시적으로 다시 요청한다.
- 기존 **저장본이 없으면 자동 번역 시작** 옵션을 따른다. 켜면 작품을 열 때 새 제목을 최대8개씩 번역해 완료 묶음부터 표시한다. 끄면 자동 요청을 보내지 않고, 수동 본문 번역 완료 시 작품 제목과 현재 회차 제목도 채운다.
- 번역 제목을 저장했다면 다음 열기·앱 재시작에서 재사용한다. 원제 변경은 해당 제목의 캐시만 무효화한다. 모델 변경만으로 기존 번역·수정값을 다시 생성하지 않는다.
- 제목 요청의 실패·결과 불명·미완료 기록은 앱 재시작 후에도 자동 재전송하지 않는다. 제목 옆의 번역/재번역으로 명시적으로 요청할 수 있다. 실패하면 기존 번역 또는 원제를 유지한다.

## 요청과 저장 경계

`titles/<workId>`의 두 슬롯 저널에 원제·번역·사용자 수정 여부·모델·시간과 요청한 제목 식별자를 저장한다. 네이티브 private 경로 허용 목록에 `titles`를 추가했다. 본문 버전·원문 스냅샷을 고쳐서 제목을 바꾸지 않는다.

로컬 제목 번역도 기존 제공자와 줄ID/컨텍스트 제한·등장 용어·확정 이름 마스킹을 사용한다. 제목마다 출력이 대응해야 하며 일본어 잔류·누락·실패 행은 저장하지 않는다. 본문으로 이동하면 제목 요청을 중단하고 native 요청이 정리될 때까지 기다린 뒤 본문을 요청한다. 모델 요청을 겹치지 않는다. 제목 요청에는 소설 본문 전문을 넣지 않으므로 짧은 제목의 의미·말투 품질은 별도 휴먼 판단 대상이다.

## 검증

전체64파일·786테스트, 타입·린트·포맷 검사, 웹 빌드, 앱 debug/계측 APK 컴파일, 생산 APK의 출처·서명·보안 감사가 통과했다. 제공자와 UI 통합 테스트는 실제 Android private 저장소 어댑터를 거친다. 제목 번역8+5묶음·수정 보존·원제 변경·재시작 복원·실패 보존·결과 불명 자동 재전송0·native 제목 정리 뒤 본문 시작을 포함한다. 계측 APK 컴파일을 전체 계측 테스트의 기기 실행으로 해석하지 않는다.
