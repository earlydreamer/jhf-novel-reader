# 작품 용어집·캐릭터 말투

#21은 #74의 컨텍스트 구간 번역과 #75의 일괄 번역 위에서 구현한다. 작품 목차의 접힌 편집기를 열어 용어·캐릭터를 직접 추가·수정·삭제하고 저장한다. 편집 중인 값은 번역에 적용하지 않는다. 용어는 원문·한국어 표기·별칭·분류·설명을, 캐릭터는 이름·별칭·말투와 호칭 지침을 담는다. 자동 후보 추출과 추정 화자 저장은 포함하지 않는다.

저장한 항목은 기기 내부 `guidance/<workId>` 두 슬롯 저널에서 검증·복원한다. 용어 40개, 캐릭터 20개, 항목별 별칭 8개까지 저장하며 글자 수 제한은 편집기에 표시한다. 저장 실패는 입력과 기존 승인 데이터를 보존한다. 손상된 기록을 읽지 못하면 빈 설정으로 덮어쓰거나 새 번역을 자동 시작하지 않는다.

회차의 원문·별칭이 실제 등장하는 항목만 참고 데이터로 제공한다. 참고 값은 JSON 인용 데이터로 구분하며 지침 자체를 번역하지 않고 확실한 화자에만 말투를 적용하도록 요청한다. 모델 출력은 기존 일반 텍스트 계약을 유지하고 문단 ID·JSON 출력 형식을 요구하지 않는다. 프롬프트 안내는 모델의 완벽한 이행을 보장하지 않으므로 실제 결과의 표기·의미 검증을 별도로 기록한다.

참고 데이터의 실제 UTF-8 길이도 보수적 입력 예산에 포함한다. 남은 예산으로 전체 원문을 순서대로 나누며, 참고 데이터가 너무 길면 생성 전에 실패한다. 항목을 자동 누락·재시도하거나 다른 제공자에게 보내지 않는다. 현재는 로컬 OpenAI 호환 구간 번역에 적용하며, 등장 항목이 있는 Gemini 요청은 지원 범위를 알리고 전송 전에 멈춘다.

승인 데이터 전체의 SHA-256를 번역 출처에 저장한다. 무관한 항목만 바뀌어도 과거 저장본을 자동으로 새 맥락의 결과로 취급하지 않는다. 항목이 없는 작품은 기존 저장본과 같은 기준을 유지한다. 기존 완성본은 계속 읽히고 수정·삭제가 재번역을 자동 시작하지 않는다.

일괄 번역의 대상 확인 때 승인 데이터를 고정해 저장한다. 기본 건너뛰기는 같은 제공자·모델·승인 데이터 해시의 완성본에만 적용한다. 대상 확인 뒤 맥락을 수정하면 시작·재개 전에 대상을 다시 확인해야 한다. 실행 중에는 편집 저장을 막고 저장 재시도는 이미 받은 결과와 원래 출처를 그대로 사용한다.

웹 검증과 실제 모델·Android 검증은 구분한다. 맥락 때문에 분할 수가 늘어나는 경우에도 원문 전체가 정확히 한 번씩 전달되는지, 오래된 대기열이 요청을 시작하지 않는지, 편집·재시작·삭제 이후에도 기존 번역을 보존하는지 확인한다.
