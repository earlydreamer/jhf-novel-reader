# 카쿠요무 Android 번역·저장·재개 검증

2026-10-26에 Black Shark 2의 기존 앱을 데이터 유지 업데이트하고, 카쿠요무 공개 작품의 추가 → 목차 선택 → 실제 모델 번역 → 저장 → 독서 → 프로세스 종료 후 재개를 확인했습니다. 원문 브라우저에서 작품을 선택하는 경로도 같은 설치본에서 확인했습니다. Refs #371, #376.

## 실제 앱에서 확인한 흐름

| 단계 | 관찰 결과 |
| --- | --- |
| 모델 연결 | 기존 설정의 `/models` 요청이 HTTP 200을 반환했고, 선택한 모델이 목록에 있었습니다. 연결 주소·모델 선택을 새로 입력하지 않았습니다. |
| URL로 작품 추가 | 카쿠요무 작품 URL로 233화 목차를 가져왔으며, 첫 회차의 순번은 1이었습니다. |
| 실제 모델 번역 | 첫 회차 343문단을 기존 OpenAI 호환 모델 연결로 번역했습니다. 저장 provenance는 `colomo-local-v1`, 14묶음, 이어 보내기 0회입니다. 미리보기에서 2/14·6/14 진행과 한국어 출력 증가를 관찰했습니다. |
| 저장·독서 | 자동 저장 후 화면이 '번역 본문'으로 바뀌고 343개 블록이 표시됐습니다. 저장 레코드에는 번역문 8,072자와 원문 343문단이 있습니다. |
| 프로세스 종료·재개 | 본문 중간 위치를 저장하고 앱을 force-stop했습니다. 이전 프로세스 종료와 새 PID를 확인한 뒤 서재의 '이어서 읽기'로 같은 versionId·chapterId의 저장본을 열었습니다. 번역문 SHA-256과 블록 수가 유지됐습니다. |
| 원문 브라우저 | 서재 '작품 찾기'에 나로우·카쿠요무가 함께 나왔습니다. 카쿠요무 메인은 Bad Request 없이 열렸고 작품 링크 91개를 확인했습니다. 작품 페이지에서 활성화된 '이 작품 열기'를 누르자 원래 작품의 233화 목차와 저장된 1화가 표시됐습니다. |

재개 직전 스크롤 값은 6,000px, 재개 후에는 5,980px였습니다. 표시되는 첫 행은 0부터 센 107번에서 106번으로 바뀌었고, 106번은 빈 줄이며 다음 107번은 같은 본문 문단입니다. 본문 중간 재개와 저장본 일치는 확인했지만 픽셀 단위로 같은 위치라고 판정하지 않습니다.

## 기존 데이터 보존

설치 전에 기존 APK와 앱 전용 `files`·`shared_prefs`를 비공개 로컬 경로에 백업했습니다. 업데이트 직후, 앱을 시작하기 전에는 기존 파일 27개가 모두 같은 SHA-256이었습니다. 그중 서재 파일은 22개입니다.

전체 검증 후에도 기존 나로우 3작품과 완성 번역 1개가 서재에 남았습니다. 기존 번역 파일·읽기 위치·작품별 목차·제목·용어집은 같은 해시를 유지했습니다. 기존 서재 파일 22개 중 18개가 그대로였으며, 바뀐 4개는 새 작품·번역을 기록한 공용 서재 인덱스 2개와 번역 시도 인덱스 2개입니다. 기존 파일이 사라진 사례는 없었습니다.

저장된 연결·모델·번역 한도·독서 설정의 값은 유지됐고, 연결 확인용 `selection.connection.revision`만 57에서 58로 증가했습니다. 앱의 연결 확인 경로는 revision을 증가시키므로 설정 파일 전체의 바이트 일치와 실제 선택값 보존을 구분합니다. Android 프로필·WebView 방문 및 환경 설정 파일의 변경도 서재 데이터 보존과 구분했습니다.

## 자동 검사와 한계

제품 소스 `09eb662`의 Claude 세션 로컬 로그에서 전체 124개 파일·1,772개 테스트와 format·lint·typecheck·build 통과를 확인했습니다. JVM Source 계열에는 `SourceBrowserPolicyTest` 16개와 `SourceSitesTest` 7개가 포함됩니다. KEY2(WebView 121)의 임시 `.a1test` 패키지 계측 13개도 통과한 기록이 있습니다. 이 세션의 새 실행은 위 APK 빌드·감사와 Black Shark 2의 실제 사용자 흐름이며, 기존 전체 검사 결과를 새로 실행한 결과로 쓰지 않습니다.

정확한 제품 head의 [Checks](https://github.com/earlydreamer/jhf-novel-reader/actions/runs/40320570089)와 [Android debug APK](https://github.com/earlydreamer/jhf-novel-reader/actions/runs/40320569933)가 성공했음을 재조회했습니다. 빌드의 기존 500kB 초과 청크 경고는 남아 있습니다.

실제 모델 번역은 공개 작품 한 회차의 기능 검증입니다. 전체 의미·말투·문학적 품질, 모든 작품의 접근 가능성, KEY2의 실제 모델 번역, 이번 APK의 백업 복원·비행기 모드 재개·iOS 동작은 확인하지 않았습니다. 원문 브라우저의 검색·필터·정렬·랭킹 전체 재측정은 앞선 별도 소스의 검증이며, 이번에는 메인 → 작품 → 선택 → 목차 복귀를 확인했습니다. 실제 소설 본문·원시 모델 입출력·인증정보·사설 주소는 공개 기록에 포함하지 않습니다.
