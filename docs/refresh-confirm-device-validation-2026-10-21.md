## 실제 나로우 URL 흐름

시험 URL은 `https://ncode.syosetu.com/n3283lf/`다. 두 기기의 기존 서재에 있던 시험 작품을 작품 추가 버튼의 URL 입력으로 다시 열어 목차 3화를 확인했다. 다른 작품이나 설정은 삭제·초기화하지 않았고 시험 작품은 서재에 남겼다. 원문 본문과 실제 번역은 실행하지 않았다.

| 검사 | Android | iOS |
| --- | --- | --- |
| 서재·작품 화면 상단 새로고침 아이콘, 본문 검사 영역 제거 | 통과 | 통과 |
| 개별·전체 모달을 연 뒤 확인 전 수동 HTTP 요청 없음 | 통과 | 통과 |
| 개별·전체 모달 취소 및 Escape 후 요청 없음 | 통과 | 통과 |
| 서재 작품 메뉴의 개별 검사도 모달 표시, 취소 후 요청 없음 | 통과 | 통과 |
| 확인하기 후 개별·전체 검사 각 1회 성공 | 통과 | 통과 |
| 마지막 검사일 `2026-10-21`, 마지막 성공 표시 | 통과 | 통과 |
| 물리 뒤로 가기로 모달만 닫기, 요청 0건 | 통과 | 별도 미실행 |

실기 WebView의 UI 동작은 디버그 자동화로 실행했으며 손가락 터치 검증으로 표시하지 않는다. Android의 물리 뒤로 가기는 실제 ADB 키 이벤트를 사용했다. iOS XCTest의 실제 URL 검사 1개는 통과했고 실패·건너뜀은 0개였다. 이번 iPhone 실행은 `-LiveSourceUrl`로 실제 URL 검사만 선택했으며 기존 합성 검사 5개를 재실행한 결과가 아니다.

응답을 대체하지 않고 네이티브 HTTP 호출을 관찰했다. 플랫폼별 총 GET 3회는 URL로 열기 1회, 확인한 개별 검사 1회, 전체 검사 1회였고 모두 HTTP 200 및 응답 바이트 수 > 0이었다. 취소·Escape·작품 메뉴 취소는 요청을 추가하지 않았다. 전체 검사는 서재에 시험 대상 작품 한 개만 있음을 확인한 뒤 실행했다.

실제 조회 사이 새 회차가 발행되지 않아 목차는 3화, 새 회차 배지는 0개였다. 실제 연재 증가를 관찰했다는 의미는 아니다. 새 회차 누적과 배지 해제는 합성 목차를 사용하는 UI 자동 테스트에서 검증했다. 날짜 기준 기본 1일/N일 검사와 자동 재시도 부재는 기존 자동 테스트를 유지했다.
