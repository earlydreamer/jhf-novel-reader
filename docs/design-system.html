데모 전용

직접 눌러 확인합니다.

앱에서 사용하는 색·글자·컴포넌트 스타일을 확인하는 문서입니다. 샘플은 네트워크 요청, 실제 번역, 파일 저장·삭제·내려받기를 실행하지 않습니다.

문서 설명은 합니다체로 작성합니다. 앱의 실제 문구는 해요체 원문과 짧은 버튼 라벨을 유지합니다. UX 라이팅 기준에서 행동과 문구의 의미를 확인합니다.

현재 구현은 소스에서 가져온 CSS와 문구로 표시합니다. 데모 조작부와 개선 제안은 별도로 표시합니다. HTML은 React 컴포넌트 자체를 실행하지 않으며 Android 실기 검증을 대체하지 않습니다.

01 · 기초

색과 표면

라이트·다크를 바꾸면 같은 의미의 토큰이 다른 값으로 표시됩니다. 본문·행동·오류는 역할별 토큰을 사용합니다.

현재 구현 · src/ui/theme/tokens.css를 그대로 포함합니다. --primary는 텍스트·행동 색이며 --primary-fill은 채운 버튼의 바탕 색입니다.

02 · 글자와 크기

글자와 크기

모서리

배치 기준

화면 본문 최대 폭은 840px이며 독서 본문은 40em입니다. 공통 터치 영역은 48px입니다. S 버튼은 시각 높이 40px와 확장된 터치 영역을 사용하며 M 버튼은 56px입니다.

화면·컴포넌트에서는 4·8·12·16·24·32px 등의 여백을 사용합니다. 별도의 spacing 토큰이 이미 구현되어 있다는 뜻은 아닙니다. 이 문서 탐색 레이아웃은 제품 화면과 구분합니다.

실제 앱은 번들 Pretendard Variable을 로드합니다. 독립 HTML은 외부 폰트를 요청하지 않고 설치된 Pretendard 또는 시스템 글꼴로 표시하므로 글자 폭은 다를 수 있습니다. 폰트 파일·라이선스를 재배포하지 않습니다.

03 · 행동

버튼과 선택

현재 구현 · filled / tonal / outlined / text, danger, disabled를 확인합니다. Tab으로 초점을 옮기고 Enter 또는 Space로 실행합니다. 위 버튼은 상태 알림만 표시합니다.

샘플 행동을 기다립니다.

현재 구현 · Button.tsx / Chip.tsx / components.css입니다. Hover는 8%, focus·pressed는 10% 상태 레이어를 사용합니다. 초점 윤곽은 3px입니다.

04 · 입력

입력과 설정

샘플 제목을 입력합니다. 실제 회차 제목은 변경하지 않습니다.

샘플 값을 입력합니다.

문서 안에서만 설정 상태를 변경합니다.

현재 구현 · 입력 표면은 application.css의 기본 입력 스타일이며 스위치는 Switch.tsx입니다. 입력 확인·오류 연결은 문서 데모·개선 제안입니다. 앱에 공통 TextField 검증 컴포넌트가 구현되어 있다는 뜻은 아닙니다.

05 · 상태 안내

진행과 오류

아래 선택기는 문서 전용 상태 조작부입니다. 실제 작업을 시작하지 않습니다.

준비·진행·오류·저장 실패·중단·완료 상태를 선택합니다.

현재 구현 · LinearProgress.tsx의 결정형·비결정형 표현과 Card.tsx의 표면을 사용합니다. 화면 문구는 BatchPanel.tsx, WorkScreen.tsx, ImmersiveReader.tsx를 따릅니다. 데모 상태 간 이동은 제품 상태 머신을 재현하지 않습니다.

06 · 확인

확인창

확인창에서도 실제 내려받기나 삭제는 실행하지 않습니다.

현재 구현 · Modal.tsx와 같은 네이티브 dialog 및 표면 스타일을 사용합니다. Esc·취소·확인 후에는 여는 버튼으로 초점을 돌려줍니다. 이 HTML은 Android 뒤로 가기 스택이나 제품의 포인터 제스처 처리를 복제하지 않습니다.

07 · 독서

독서 배경

1화 · 합성 본문

이 문장은 글자와 배경을 확인하기 위한 합성 예문입니다. 실제 소설 내용이나 사용자 데이터는 포함하지 않습니다.

본문 폭, 행간, 긴 단어의 줄바꿈을 확인합니다. 외부 모델 요청이나 번역을 실행하지 않습니다.

현재 구현 · tokens.css의 독서 색 범위를 사용합니다. 앱에서는 세피아와 라이트, 검정과 다크를 함께 적용합니다. 이 문서에서는 주변 UI를 유지하고 샘플 영역의 독서 색만 표시합니다.

08 · 구현 기준

구현 대응표

토큰·글자·크기

src/ui/theme/tokens.css와 base.css를 기준으로 합니다. 색과 컴포넌트 CSS는 2b6d26f의 스냅샷을 HTML에 포함합니다. 정본 변경 시 이 문서도 동기화합니다.

공통 행동·표면

src/ui/components/{Button,Chip,Card,Switch,LinearProgress,Modal}.tsx와 components.css를 기준으로 합니다. standalone HTML은 같은 클래스와 의미를 사용한 데모 마크업입니다.

문구와 흐름

src/ui/{SettingsScreen,WorkScreen,BatchPanel,ImmersiveReader}.tsx를 기준으로 합니다. 원문·완성본·저장 실패·중복 요청의 차이는 UX 라이팅 문서에서 설명합니다.

샘플에서 다루지 않는 범위

전체 화면 라우팅, 실제 API, 스낵바 큐, Android 시스템 바, 네이티브 뒤로 가기, 실제 파일 작업은 실행하지 않습니다. 앱의 모든 컴포넌트·상태를 빠짐없이 복제한 카탈로그가 아닙니다.
