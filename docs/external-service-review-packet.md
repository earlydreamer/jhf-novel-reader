# 외부 서비스·개인정보 검토 자료

검토일: 2026-10-26 · 관련 이슈: [#336](https://github.com/earlydreamer/jhf-novel-reader/issues/336)

이 문서는 무료 MIT 공개 배포와 기기 직접 연결을 전제로 작성한 검토 자료이며, 정식 개인정보처리방침이나 외부 서비스 도입 결정이 아닙니다. 현재 배포판에서 확인한 사실, 공식 자료에서 확인한 조건, 앞으로 제품에 제안하는 조치를 나누어 적었습니다. 이 자료를 작성하면서 제품 코드와 로그인·추론 경로는 바꾸지 않았습니다.

## 1. 확정한 범위와 남은 결정

| 항목 | 2026-10-26 기준 |
| --- | --- |
| 배포·라이선스 | 무료 MIT 오픈소스이며 현재는 GitHub에서 직접 설치하는 방식을 지원합니다. 스토어 배포 가능성은 앞으로 검토합니다. MIT는 소스 이용 조건이므로 개인정보 관련 의무나 제공자 계약을 면제하지 않습니다. |
| 연결 방식 | 기기가 원문 사이트와 사용자가 지정한 모델 서버에 직접 연결하며, 개발자가 운영하는 중계 서버는 전제하지 않습니다. 사용자가 지정하는 서버는 같은 기기, 사설망, 외부 호스팅 가운데 어디에나 있을 수 있습니다. |
| 운영 정책 | 개발자는 독서 데이터와 인증정보를 직접 수집하지 않고 기기에 저장하는 정책을 유지합니다. 외부 사이트와 모델 제공자가 받는 데이터는 따로 설명합니다. |
| 추가 후보 | ChatGPT 로그인과 플랜 연결은 도입 여부가 정해지지 않았습니다. Gemini 유료 검증은 #29에서 보류 중입니다. |
| 미확정 | 운영 주체의 공개 명칭과 연락처, 대상 국가와 연령, 기존 별도 방침의 원본과 게시 URL, 스토어 계정과 출시 일정, 지원할 제공자와 계정 유형이 아직 정해지지 않았습니다. 전 세계에 공개될 수 있다는 사실만으로 모든 국가를 지원 대상으로 정하지 않습니다. |

현행 소스의 기준은 main `39714b459ea85bddc73935d291a6987e5c62741e`입니다. ChatGPT 연구 브랜치는 조회 시점의 head가 `ad0d7c75e3e63decdf72f1e7cf52db3da92188d2`이며 제품 main에는 들어 있지 않습니다. 연구 당시 실측한 소스와 이번 문서 검토를 새 제품의 실기 결과로 합산하지 않습니다.

저장소에서는 [README의 연결 안내](../README.md#개인정보와-연결)를 확인했습니다. 별도의 정식 방침, 앱 안의 방침 링크, 외부 게시 위치는 검색으로 찾지 못했습니다. 저장소 밖에 원본이 없다는 뜻은 아닙니다.

현재 README의 “앱 전용 저장소에만 있습니다”, “앱이 연결하는 곳은 다음이 전부입니다”는 6절에서 쓰지 않기로 한 문구 유형에 해당합니다. README 표에는 카쿠요무와 Hugging Face의 CDN 호스트, 수동 백업 ZIP의 외부 저장, 번역 요청에 포함되는 요약·참고자료·이전 문맥이 빠져 있습니다. README 수정안은 이 자료와 별도로 근거를 붙여 따로 확인받습니다.

## 2. 현행 데이터 흐름과 확인 근거

아래 표의 전송은 개발자 서버의 수집과 구분합니다. 연결 상대는 통신 과정에서 IP, 요청 시각, User-Agent 같은 접속 정보를 볼 수 있습니다. 다만 각 서버가 실제로 어떤 항목을 기록하고 얼마나 보관하는지는 이 코드로 확인할 수 없습니다.

Android의 `allowBackup=false`는 [Manifest](../android/app/src/main/AndroidManifest.xml)의 시스템 백업 설정이며, 수동 ZIP이나 사용자가 보관한 사본을 막거나 지우지는 않습니다. [Capacitor 설정](../capacitor.config.ts)에서 로그를 끈 것도 모든 플러그인, 제공자, OS에 로그가 없다는 증명은 아닙니다.

npm 런타임 의존성에는 분석·진단 SDK가 없습니다. [Android 빌드 설정](../android/app/build.gradle)의 `google-services` 플러그인은 Capacitor 템플릿의 기본값이며, `google-services.json`이 없어 적용되지 않습니다. LiteRT-LM은 기기 내 임베딩에만 쓰이지만 SDK 자체의 네트워크 동작은 확인하지 않았습니다. 이번 검토는 관련 코드와 목적지를 검색한 결과이며, SDK 전체나 패킷, 릴리스 바이너리를 감사한 것은 아닙니다.

Gemini의 [기존 전체 회차 요청 코드](../src/providers/gemini/wholeChapter.ts)는 본문과 지시를 Google로 보내는 경로입니다. 현재 UI에서 숨긴 과거 구현이며, 이번 검토에서 이 기능을 다시 켜지 않았습니다.

## 4. 한국·글로벌·스토어 기준을 적용하는 방법

### 한국

[개인정보 포털 안내서 목록](https://www.privacy.go.kr/front/bbs/bbsList.do?bbsNo=BBSMSTR_000000000049)에서 2026 개인정보 처리방침 작성지침이 2026-04-24에 등록된 것을 확인했습니다. [개인정보위의 4월 28일 설명회 안내](https://pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS074&mCode=C020010000&nttId=12030)도 확인했습니다. [원본 게시물](https://www.privacy.go.kr/front/bbs/bbsView.do?bbsNo=BBSMSTR_000000000049&bbscttNo=20885)은 두 번 모두 502 오류가 나서 첨부된 지침 전문은 읽지 못했습니다. 따라서 아래 항목은 법 조문과 이번 데이터 분석을 바탕으로 만든 검토 목록이며, 지침 전문과 대조한 결과가 아닙니다.

[개인정보 보호법 제30조](https://law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1033214957)와 [제28조의8](https://law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1020398611)은 조회한 페이지 기준으로 시행일이 2026-09-11입니다. 개인정보처리자에 해당한다면 처리방침과 국외 이전의 근거·고지 항목을 검토해야 합니다. 개발자가 데이터를 받지 않는 기기 직접 연결 구조에서 누가 처리 목적과 수단을 정하는지, 어떤 데이터가 개인정보인지, 제공·위탁·국외 이전에 해당하는지는 검토자가 실제 구조를 보고 판단할 항목입니다. 무료이고 MIT이며 개발자 중계가 없다는 사실만으로 법 적용이 제외된다고 확정하지 않습니다.

권고하는 검토 순서는 다음과 같습니다.

1. 독서 데이터, 조회어, 토큰과 계정 식별자, 접속 정보가 개인정보에 해당할 수 있는지 기능별로 확인합니다. 소설 본문도 개인정보를 담을 수 있다는 전제로 확인합니다.
2. 개발자, 사용자가 지정한 서버의 운영자, 외부 제공자의 역할을 나눕니다. 독립된 제공자를 일괄해서 개발자의 수탁자로 적지 않습니다.
3. 처리 목적, 항목, 보유 기간, 삭제 절차, 제공·위탁, 국외 이전, 권리 행사, 안전조치, 연락처 가운데 적용되는 항목을 실제 운영에 맞게 채웁니다. 해당하지 않는 처리는 없다고 설명하고 그 근거를 남깁니다.
4. 동의가 필요한 처리와 다른 법적 근거에 따른 처리를 구분합니다. 방침 게시, 앱의 전송 확인, 법률상 동의, 제공자 약관 수락은 서로 다른 절차이므로 체크박스 하나로 대신하지 않습니다.

## 6. 방침과 연결 시점 안내의 검토 초안

아래 문구는 채택 전 검토용입니다. 공개 운영자, 연락처, 효력일, 지역, 연령, 실제 삭제 절차가 정해지기 전에는 정식 방침으로 게시하지 않습니다. 현재 기능과 후보 기능을 한 문장에 섞어 후보 기능이 이미 출시된 것처럼 쓰지 않습니다.

### 현재 배포판의 짧은 설명 후보

> JHF Novel Reader는 독서 자료와 설정을 기기에 저장합니다. 개발자는 앱에서 원문, 번역, 읽기 기록, 인증정보를 직접 수집하는 서버를 운영하지 않습니다. 원문을 가져오거나, 선택한 서버로 번역하거나, 용어를 조회하거나, 기기 내 판정 모델을 내려받으면 그 기능에 필요한 내용이 기기에서 해당 사이트나 서버로 직접 전송됩니다. 백업 파일을 만들면 사용자가 고른 저장 위치에 기록됩니다. 외부 서비스가 이 정보를 어떻게 보관하고 이용하는지는 해당 운영자의 정책을 확인해 주세요.

영문 대응 초안:

> JHF Novel Reader stores reading data and settings on your device. The developer does not operate a server that collects your novel text, translations, reading history, or credentials from the app. Fetching source text, translating with a server you select, looking up terms, and downloading the on-device model send the information needed for those features directly from your device to the relevant site or server. Creating a backup writes a file to the storage location you choose. Check the external operator's policy for how it retains and uses that information.

“개인정보를 전혀 처리하지 않습니다”, “모든 데이터가 항상 기기에만 있습니다”, “어떤 제3자에게도 전송하지 않습니다”는 현재 네트워크 기능과 맞지 않으므로 쓰지 않습니다.

### 외부 모델 연결 시점 안내 후보

> 선택한 서버로 번역할 원문과 번역 지시를 보냅니다. 기능에 따라 제목, 용어 참고자료, 요약, 이전 번역 문맥도 포함될 수 있습니다. 서버 운영자가 입력과 결과를 보관하거나 다른 목적으로 쓰는지는 해당 서버의 정책을 확인하세요. 인증값은 연결과 요청 인증에 씁니다. 보내는 자료에 개인정보나 공개하면 안 되는 내용이 없는지 확인하세요.

설정 화면에서 서버 주소, 운영자, 방침 링크를 함께 보여 주고 사용자가 확인한 뒤 연결하는 방식을 제안합니다. 아직 구현하지 않은 UX이며, 현재 앱이 필요한 동의 절차를 모두 갖췄다는 뜻이 아닙니다. 전송 권한과 저작권 검토도 따로 남아 있습니다.

ChatGPT를 채택한다면 이 안내와 별도로 제공자 로그인, 공유되는 사용량과 한도, 토큰 보호 저장, 외부 원문 전송을 설명해야 합니다. 연결을 해제할 때는 로컬 토큰 삭제와 서버 측 철회 결과를 구분하고, 네트워크 오류로 철회를 확인하지 못한 상태를 성공으로 표시하지 않도록 제안합니다. 앱에서 연결을 해제해도 OpenAI 계정이 삭제되거나 이미 보낸 콘텐츠가 모두 지워지는 것은 아니라는 점을 명시해야 합니다.

## 7. 스토어 제출 전에 채울 작업표

아래 표는 제출 답안이 아니며, 출시할 패키지와 SDK를 고정한 뒤 채울 검토표입니다. Apple과 Google에 같은 “수집 없음” 답을 그대로 쓰지 않습니다.

| 흐름 | 검토할 데이터 유형 후보 | 확정할 근거 |
| --- | --- | --- |
| 로컬 서재·독서 위치 | 기기 내 콘텐츠, 사용 상태 | 해당 릴리스에 자동 업로드, 진단, 플러그인 전송이 없는지 확인합니다. 기기 안에서만 처리한다면 각 스토어의 로컬 처리 제외 정의와 대조합니다. |
| 외부 모델 번역 | 사용자 콘텐츠(문서·텍스트), 요청에 포함되는 식별·인증 항목 | 실제 전송 필드, 수신자의 보관, 계정 연결 여부, 목적, 필수·선택 여부를 확인합니다. 현재는 `http://` 서버를 지정할 수 있으므로 “전송 중 암호화” 항목에 일괄로 “예”라고 답하지 않습니다. HTTPS를 강제할지, 평문 연결에 경고를 띄울지 먼저 정합니다. 보내는 텍스트가 개인 식별과 무관한지도 따져 봅니다. |
| 용어 조회·원문 탐색 | 검색어, 탐색 내용, 접속 정보 | 앱이 제어하는 요청과 열린 웹 탐색을 구분합니다. IP로 위치를 추정하는지 같은 사항은 실제 제공자의 처리에 따라 판단합니다. |
| ChatGPT 후보 | 계정·사용자 식별자, 호스트 식별자, 토큰, 콘텐츠 | 토큰 값을 수집 공시에 그대로 드러내지 않습니다. SDK, 계약, 보관, 계정 연결과 한도 처리를 확인한 뒤 유형을 정합니다. |
| 백업·사용자 공유·제보 | 사용자가 고른 파일, 지원 요청 첨부 | 사용자가 고른 시스템 문서 제공자에 저장하는 경우와 개발자가 받는 경우를 구분하고, 공유 예외와 양식 요구 사항을 검토합니다. |
| 의존 SDK·릴리스 바이너리 | 진단, 식별자, 사용 데이터 등 실제 항목 | 전체 의존성, manifest, 네트워크를 점검합니다. 설정 파일 하나나 오픈소스라는 사실로 무수집을 증명할 수는 없습니다. |

계정 생성 기능이 추가되면 스토어의 계정 삭제 요건을 다시 적용합니다. 먼저 ChatGPT 외부 계정 연결만 두는지, JHF 자체 계정을 만드는지부터 정합니다. 현재 정책상 광고와 추적을 넣지 않으므로, ATT나 판매·공유 옵트아웃을 형식적으로 붙이기보다 실제 데이터 사용과 적용 요건을 먼저 확인합니다.

## 9. 이번 자료의 검증 범위
