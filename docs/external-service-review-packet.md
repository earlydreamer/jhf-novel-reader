Gemini의 [기존 전체 회차 요청 코드](../src/providers/gemini/wholeChapter.ts)는 본문과 지시를 Google에 보내는 경로입니다. 현재 UI에서 숨겨진 과거 구현이며, 이번 검토로 기능을 활성화하지 않습니다.

## 4. 한국·글로벌·스토어 기준을 적용하는 방법

### 한국

[개인정보 포털 안내서 목록](https://www.privacy.go.kr/front/bbs/bbsList.do?bbsNo=BBSMSTR_000000000049)에서 **2026 개인정보 처리방침 작성지침, 2026-04-24 등록**을 확인했습니다. [개인정보위의 4월 28일 설명회 안내](https://pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS074&mCode=C020010000&nttId=12030)도 확인했습니다. [원본 게시물](https://www.privacy.go.kr/front/bbs/bbsView.do?bbsNo=BBSMSTR_000000000049&bbscttNo=20885)은 두 차례 502여서 첨부 지침 전문은 읽지 못했습니다. 아래 항목은 법 조문과 이번 데이터 분석을 토대로 한 검토 목록이며 지침 전문 대조 완료를 뜻하지 않습니다.

[개인정보 보호법 제30조](https://law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1033214957)와 [제28조의8](https://law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1020398611)은 조회된 페이지상 시행일이 2026-09-11입니다. 개인정보처리자에 해당하는 경우 처리방침과 국외 이전의 근거·고지 항목을 검토해야 합니다. 개발자가 수신하지 않는 기기 직접 연결에서 누가 처리 목적·수단을 결정하는지, 어떤 데이터가 개인정보인지, 제공·위탁·국외 이전에 해당하는지는 검토자가 실제 구조로 판단할 항목입니다. 무료·MIT·개발자 중계 부재만으로 적용 제외를 확정하지 않습니다.

권고하는 검토 순서는 다음과 같습니다.

1. 독서 데이터, 조회어, 토큰·계정 식별자와 접속 정보의 개인정보 해당 가능성을 기능별로 확인합니다. 소설 본문이 항상 비개인정보라고 가정하지 않습니다.
2. 개발자·사용자 지정 서버 운영자·외부 제공자의 역할을 나눕니다. 독립된 제공자 모두를 개발자의 수탁자라고 쓰지 않습니다.
3. 적용되는 처리 목적·항목·보유 기간·삭제 절차·제공/위탁·국외 이전·권리 행사·안전조치·연락처를 실제 운영에 맞게 채웁니다. 해당 없는 처리는 없다고 설명하되 근거를 남깁니다.
4. 동의가 필요한 처리와 다른 법적 근거를 구분합니다. 방침 게시·앱의 전송 확인·법률상 동의·제공자 약관 수락을 하나의 체크박스로 대체하지 않습니다.

### 글로벌

[EU 집행위 적용 범위 안내](https://commission.europa.eu/law/law-topic/data-protection/information-business-and-organisations/application-gdpr_en)는 EU 밖 사업자의 EU 대상 서비스 제공에도 무료 여부와 무관하게 GDPR이 적용될 수 있다고 설명합니다. 단순 웹 접근 가능성과 EU 대상 제공·행동 모니터링을 구분하고 실제 배포 범위를 검토합니다. [정보 제공 안내](https://commission.europa.eu/law/law-topic/data-protection/information-individuals_en)에 맞춰 적용 시 책임자·목적/근거·수신자·기간·권리·이전 설명을 명료하게 준비합니다. EUR-Lex 본문 열람은 접근 확인 화면으로 막혔으므로 조문 전체의 이번 직접 열람을 주장하지 않습니다. UK 등 다른 관할은 별도 확인이 필요합니다.

[California DOJ의 CCPA 안내](https://oag.ca.gov/privacy/ccpa)는 캘리포니아에서 사업하는 영리 사업자의 적용 요건을 제시합니다. JHF의 무료 MIT 배포만으로 적용 여부를 확정하지 않으며 운영 주체·규모·수익·판매/공유 구조가 바뀔 때 재검토합니다. 없는 광고·판매를 방침에 만들어 넣거나 타사 템플릿의 권리 행사·응답 기한을 근거 없이 약속하지 않습니다. 이번 자료는 모든 국가의 법률 조사나 적합 판정은 아닙니다.
