# 외부 서비스 연동 연구와 제품 도입 결정

2026-10-15 사용자 결정입니다. ChatGPT 연동은 도입 미확정 연구이며 main에 병합하지 않습니다. 기술 검증 성공과 CI 통과는 서비스 제공자의 정책 확인, 개인정보·법률 검토 또는 제품 도입 승인을 대신하지 않습니다. 이 결정과 후속 작업은 [#334](https://github.com/earlydreamer/jhf-novel-reader/issues/334)에서 관리합니다.

## 연구 코드의 위치와 보존 범위

- 연구 브랜치: [`codex/research-external-services`](https://github.com/earlydreamer/jhf-novel-reader/tree/codex/research-external-services)
- ChatGPT 연구: [#307](https://github.com/earlydreamer/jhf-novel-reader/issues/307), main 대상 [PR #333](https://github.com/earlydreamer/jhf-novel-reader/pull/333)은 미병합 종료했습니다. 실험 커밋과 기기 검증 문서는 연구 브랜치에 보존합니다.
- 실제 성공을 확인한 구현 소스는 `3fc2854a84c96a71f61acb3d0202835a86232028`이며, 이후 문서 커밋을 새 APK 실측으로 취급하지 않습니다.
- 연구 범위는 별도 패키지의 합성 입력 PoC입니다. 제품 제공자·설정·독서 저장 경로·릴리스에는 연결하지 않았습니다. 이전 실제 세션은 철회·삭제했습니다.
- [Gemini #29](https://github.com/earlydreamer/jhf-novel-reader/issues/29)는 보류를 유지합니다. 이미 main에 있는 숨겨진 과거 구현은 이 문서로 활성화하거나 연구 브랜치로 임의 이동하지 않습니다.

연구 브랜치는 main으로 일괄 병합할 후보가 아닙니다. 향후 도입이 결정되면 승인된 기능만 최신 main에서 별도 이슈·구현 PR로 제안하고 필요한 연구 코드를 검토합니다. 연구 재개·로그인·모델 호출·사용량 소비도 각 실행 범위가 필요하며, 코드 보존이 추가 실행 동의를 뜻하지 않습니다.

## 현재 확인한 것과 미결정 사항

ChatGPT PoC는 Android 10·Chrome 149 한 조합에서 인증·보호 저장·갱신·계정 모델 목록·합성 번역과 철회를 확인했습니다. 장기 세션과 모든 잠금·취소·종료 조합을 검증한 것은 아닙니다. 상용 배포·지역별 자격·계약상 권한·개인정보 처리의 적합성도 미확정입니다.

저장소에는 [README의 개인정보와 연결 안내](../README.md#개인정보와-연결)가 있습니다. 현재 main의 연결 대상과 전송 항목을 설명하지만, 별도의 정식 개인정보처리방침 파일·제품 내 방침 링크·외부 게시 URL은 저장소 검색에서 확인하지 못했습니다. 저장소 밖의 정책이 없다는 뜻은 아닙니다. 기존 방침의 원본·게시 위치·책임자를 확인하기 전 준수 여부나 방침 완성을 선언하지 않습니다.

현재 앱도 원문 사이트·사용자 지정 번역 서버·선택적 용어 조회 등 네트워크 경로가 있습니다. 로컬 저장·개발자 서버 부재만으로 외부 제공자 도입의 데이터 처리 책임을 결론내리지 않습니다. 사용자 지정 서버의 기존 동작과 새로 검토하는 제공자 연동의 범위를 구분합니다.

## 다음 작업의 순서와 결정 책임

| 단계 | 준비할 산출물 | 결정 주체와 다음 단계 조건 |
| --- | --- | --- |
| 1. 제품·배포 범위 | 운영 주체, 개인 사용/공개 배포, 무료/유료, 대상 지역·연령, 기기 직접 연결/중계 서버 여부 | 유지관리자가 사실을 정리하고 제품 책임자가 범위를 선택합니다. 미정인 관할·대상 사용자를 임의로 가정하지 않습니다. |
| 2. 제공자 정책 확인 | 계정·플랜·워크스페이스 자격, 해당 연동 방식의 허용 범위, 명칭/표시, 한도·과금, 보관·학습·삭제 조건과 공식 근거 | 제공자별로 확인합니다. 문서로 해결되지 않는 내용은 공식 문의에 사용할 질문을 준비하고 답변을 기록합니다. 이 작업에서 문의를 발송하지 않습니다. |
| 3. 데이터 처리·방침·법률 검토 | 아래 데이터 표, 기존 방침과의 차이, 필요한 고지·동의·권리 행사·계약 문서 초안 | 실제 운영·배포 범위를 기준으로 법률 검토를 의뢰할 자료를 준비합니다. 법률 검토자는 적용 법률과 필요한 절차를 판단하고, 책임자는 미해결 항목을 기록합니다. |
| 4. 제품 도입 판단 | 지원/보류/중단 결론, 지원 기능, 외부 전송 안내, 비용과 연결 해제 UX, 남은 기술 위험 | 제공자 정책·개인정보·법률 검토 결과를 바탕으로 사용자가 명시적으로 도입 여부를 결정합니다. 기술 성공만으로 이 단계를 통과하지 않습니다. |
| 5. 선택된 기능 구현 | 승인된 좁은 기능의 별도 이슈·PR, 실제 전송과 고지의 일치, 필요한 기기·세션 검증 | 앞 단계가 완료된 범위만 구현합니다. main 병합과 배포는 각 PR의 검토·CI·완료 조건을 따릅니다. |

현재는 연구 결과 보존과 검토 자료 준비 단계입니다. 위 표는 검토 업무의 순서이며 법률 적합 판정이나 도입 승인 기록이 아닙니다. #330 공통 용어집은 별도의 후순위 기능으로 유지하며 이 연구 보류를 이유로 자동 착수하지 않습니다.

방침·법률 검토 자료에는 운영 주체/연락처, 처리 목적·항목·기간, 제공자·수신자·처리 위치, 위탁/제공/국외 처리의 해당 여부와 근거, 이용자 권리·연령 조건, 안전조치·사고 대응, 방침 변경·게시 위치를 포함합니다. 이 항목의 법적 성격과 필요한 동의·계약·절차는 대상 지역과 운영 구조를 확정한 뒤 검토자가 판단합니다. 실제 계정 정보·토큰·소설 원문을 공개 검토 자료에 넣지 않습니다.

다음 준비 작업은 제품·배포 범위와 기존 개인정보처리방침 원본을 확인하고, 후보 기능별 데이터 표와 제공자 질의 목록을 채우는 것입니다. 정식 방침 문구를 사실보다 먼저 확정하거나 법률 검토 없이 게시하지 않습니다. 이 작업은 외부 연락·실계정 재인증·원문 전송을 포함하지 않습니다.
