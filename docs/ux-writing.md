# UX 라이팅 기준

## 목적과 적용 범위

이 문서는 JHF Novel Reader의 행동·안내·오류·진행 상태 문구를 명시적으로 관리합니다. [클릭 가능한 디자인 시스템](design-system.html)과 함께 사용합니다. 구현 확인 기준은 `2b6d26f`이며, 이후 변경 시 아래 소스와 예시를 함께 갱신합니다.

문서는 **합니다·입니다체**로만 작성합니다. 해요체는 앱 화면 문구에만 사용합니다. 문서에서 앱 문구를 다룰 때에는 해요체 원문을 옮기지 않고 전달하는 내용을 합니다체로 설명한 뒤 구현 위치를 적습니다. 정확한 문구는 소스에서 확인합니다. 짧은 행동 라벨은 그대로 인용합니다. 문서 말투 변경을 제품 문구 일괄 변경으로 해석하지 않습니다. 실제 UI의 기준은 [DESIGN.md](../DESIGN.md)와 소스이며, 이 문서는 제품 동작을 추가하거나 변경하지 않습니다.

- **현재 구현**은 확인한 코드·문구·동작을 설명합니다.
- **작성·검토 원칙**은 새 문구를 만들거나 기존 문구를 수정할 때 적용합니다. 기존 모든 문구가 이미 통일되었다는 뜻은 아닙니다.
- **개선 제안**은 아직 제품에 반영하지 않은 항목입니다. 구현 사실처럼 표현하지 않습니다.

## 작성·검토 원칙

1. 사용자가 하려는 행동과 결과를 먼저 설명합니다. 내부 오류 코드·작업 식별자보다 사용자가 확인할 위치와 다음 행동을 제시합니다.
2. 버튼은 짧은 동사형 라벨을 사용합니다. 범위가 중요한 경우 `이 화`, `남은 회차`, `모델 요청 없이`처럼 대상을 명시합니다. 설명 문장을 버튼에 옮겨 넣는 방식은 피합니다.
3. 확인된 사실만 완료로 표현합니다. 모델 목록 조회, 번역 호환성 확인, 응답 수신, 완성본 검증, 기기 저장을 서로 구분합니다.
4. 실패 안내는 가능한 경우 `무엇이 일어났는지 → 무엇을 확인하거나 할 수 있는지` 순서로 작성합니다. 원인을 확인하지 못했다면 추정 원인을 단정하지 않습니다.
5. 삭제·복원·외부 조회·모델 내려받기 전에 대상, 범위, 되돌릴 수 있는지, 외부 전송 또는 비용 가능성을 설명합니다.
6. 취소·중단·닫기를 구분합니다. 창을 닫아도 작업이 계속된다면 그 사실과 다시 여는 위치를 알립니다.
7. 안내에 인증값·개인 서버 주소·실제 소설 본문·원시 모델 응답을 포함하지 않습니다. 문서와 테스트에는 합성 데이터를 사용합니다.
8. 색만으로 상태를 전달하지 않습니다. 상태 문구와 접근성 이름을 제공하며 아이콘 전용 버튼에는 행동을 설명하는 이름을 붙입니다.

## 용어와 행동 범위

| 용어                               | 사용 기준                                                                                                                                           |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 작품 / 회차 / 화                   | 작품은 소설 전체를, 회차는 개별 항목을 의미합니다. 숫자와 함께 표시할 때에는 `1화`처럼 사용합니다.                                                  |
| 원문 / 번역 / 저장본               | 원문은 소스 본문을, 번역은 생성 과정 또는 결과를, 저장본은 기기에 보관된 결과를 의미합니다. 스트리밍 중간 표시를 완성 저장본이라고 부르지 않습니다. |
| 읽으며 번역                        | 현재 로컬 번역 방식 이름입니다. `기존 묶음 방식`과 구분합니다.                                                                                      |
| 미리 번역하기 / 일괄 번역          | 작품 화면의 진입 명칭과 범위 처리 문맥에 사용합니다. 현재 코드가 두 표현을 사용하므로 문서에서 임의로 하나로 치환하지 않습니다.                     |
| 용어집 / 용어 정밀스캔 / 판정 모델 | 확정 용어 데이터, 후보 수집·검토 흐름, 기기 내 판정용 모델을 구분합니다. 판정 모델 내려받기를 소설 번역 다운로드라고 표현하지 않습니다.             |
| 다시 시도 / 재개 / 다시 번역       | 실패한 동작 재실행, 남은 작업 이어서 실행, 새로운 번역 요청을 구분합니다. 저장 재시도는 모델 요청 재전송과 구분합니다.                              |
| 취소 / 중단 / 닫기                 | 확인창에서 행동을 실행하지 않는 것, 진행 중인 작업을 멈추는 것, 화면만 닫는 것을 구분합니다. 실제 동작에 맞추어 사용합니다.                         |
| 내려받기 / 백업 / 복원             | 모델 파일을 받는 것, 현재 데이터를 파일로 저장하는 것, 백업 내용으로 현재 데이터를 바꾸는 것을 구분합니다.                                          |

## 현재 구현 문구와 상태

아래 표는 현재 UI 문구가 전달하는 내용을 설명합니다. 정확한 문구는 구현 위치의 소스에서 확인합니다. 해요체가 아닌 진행률 표시 형식만 그대로 인용합니다.

| 상황           | 안내 내용                                                                                              | 구현 위치·의미                                                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| 연결 확인      | 모델 목록을 확인했고 번역 호환성은 아직 확인하지 않았다고 알립니다.                                    | `SettingsScreen.tsx`의 연결 상태 문구입니다. 목록 확인만으로 실제 번역 성공을 보장하지 않습니다.                           |
| 연결 실패      | 서버에 연결하지 못했다고 알리고 주소와 서버 상태를 확인하도록 안내합니다.                              | `ImmersiveReader.tsx`의 `connection` 오류입니다.                                                                           |
| 인증 실패      | 서버 인증에 실패했다고 알리고 연결 설정에서 인증 정보를 확인하도록 안내합니다.                         | `ImmersiveReader.tsx`의 `auth` 오류입니다. 인증값을 화면에 되풀이하지 않습니다.                                            |
| 입력 한도 초과 | 선택한 모델의 입력 한도를 넘었다고 알리고 용어집·말투 항목을 줄이거나 다른 모델을 고르도록 안내합니다. | `ImmersiveReader.tsx`의 `input_limit` 오류입니다.                                                                          |
| 불완전한 응답  | 응답이 출력 길이 제한에 도달해 완성본으로 저장하지 않았다고 알립니다.                                  | `ImmersiveReader.tsx`의 `output_limit` 오류입니다. 응답과 완성 저장본을 구분합니다.                                        |
| 준비 중        | 전체 목차와 번역할 회차를 확인하는 중이라고 표시합니다.                                                | `BatchPanel.tsx`의 `preparing` 상태입니다.                                                                                 |
| 원문 확인 중   | 모델 요청 없이 원문을 확인하는 중이라고 표시합니다.                                                    | `BatchPanel.tsx`의 원문 준비 상태입니다. 모델 요청 여부를 구분합니다.                                                      |
| 진행률         | “미리 번역하는 중 · 2/10화”                                                                            | `WorkScreen.tsx`의 `cursor/chapters.length` 표시 형식에 합성 숫자를 넣은 예시입니다. 예상 소요 시간으로 해석하지 않습니다. |
| 중단           | 일괄 번역이 중단됐고 완료본은 그대로 남아 있다고 알립니다.                                             | `BatchPanel.tsx`의 중단 상태입니다. `남은 회차 번역 재개` 행동으로 연결합니다.                                             |
| 저장 실패      | 완료한 번역을 저장하지 못했으며 새로 요청하기 전에 저장을 마쳐야 한다고 알립니다.                      | `BatchPanel.tsx`의 저장 재시도 상태입니다. 행동 라벨은 `모델 요청 없이 일괄 결과 저장 다시 시도`입니다.                    |
| 완료           | 일괄 번역을 마쳤고 목차에서 저장된 회차를 열어 읽을 수 있다고 알립니다.                                | `BatchPanel.tsx`의 완료 상태입니다.                                                                                        |
| 삭제 확인      | 이 화의 번역 저장본과 읽던 위치가 이 기기에서 삭제되며 되돌릴 수 없다고 알립니다.                      | `WorkScreen.tsx`의 회차 저장본 삭제 확인입니다. 작품 전체 삭제나 원문 사이트 삭제가 아닙니다.                              |
| 화면만 닫기    | 정밀스캔은 계속 진행되며 메뉴의 `용어 정밀스캔`에서 다시 볼 수 있다고 알립니다.                        | `WorkScreen.tsx`의 스캔 창 닫기 안내입니다. 닫기를 중단으로 표현하지 않습니다.                                             |

## 재시도와 중복 요청

현재 `BatchPanel.tsx`는 이전 요청의 결과를 확인할 수 없는 상황에서 그 사실과 함께, 다시 요청하면 중복으로 처리되거나 비용이 생길 수 있다고 안내합니다. 행동 라벨은 `중복 처리 가능성을 확인하고 일괄 번역 재개`입니다.

저장 실패를 번역 실패라고 뭉뚱그리거나 무조건 `다시 시도`로 처리하지 않습니다. 다음 세 상황을 구분하여 검토합니다.

- 결과가 있고 저장만 실패했다면 모델 요청 없이 저장을 다시 시도합니다.
- 요청 완료 여부가 불명확하다면 중복 처리·비용 가능성을 안내하고 사용자의 명시적 행동을 기다립니다.
- 검증에 실패한 문단 자동 재번역 설정은 한 번 더 요청하며 비용이 생길 수 있음을 설명합니다. 결과를 확인할 수 없는 요청까지 자동으로 다시 보낸다고 표현하지 않습니다.

## 내려받기와 외부 전송

현재 판정 모델 확인창은 판정 모델을 내려받을지 묻는 제목과 `취소`·`내려받기` 버튼을 사용합니다. 본문은 다음 세 가지를 알립니다.

- EmbeddingGemma 2(약 165MB)를 Hugging Face에서 내려받아 이 기기에 저장합니다.
- Wi-Fi에서 받기를 권장합니다.
- 원문과 번역은 기기 밖으로 보내지 않습니다.

이는 `SettingsScreen.tsx`의 기기 판정 모델 흐름에 한정된 안내입니다. 다른 번역 서버 요청까지 원문이 기기 밖으로 나가지 않는다고 일반화하지 않습니다. 파일 크기·모델·출처가 바뀌면 구현과 문서를 함께 갱신합니다.

용어 정밀스캔의 외부 조회 확인창은 일본어 용어 이름을 보내는 대상 사이트를 밝히고 회차 본문과 번역문을 보내지 않는다고 설명합니다. 백업 안내는 API 키와 기기 판정 모델을 백업에 넣지 않는다고 설명합니다. 이처럼 전송·보관·제외 대상을 구체적으로 적습니다.

## 짧은 라벨과 문장

- 버튼은 `취소`, `닫기`, `내려받기`, `삭제하기`, `다시 시도`, `남은 회차 번역 재개`처럼 표시합니다. 버튼을 모두 합니다체 문장으로 바꾸지 않습니다.
- 문서 설명은 “삭제 범위를 안내합니다.”처럼 작성합니다.
- 앱 문구는 “삭제한 내용은 되돌릴 수 없다고 알립니다.”처럼 내용을 설명하고, 정확한 문구는 소스에서 확인합니다.
- 상태 문구는 진행과 완료를 구분합니다. 실패하거나 확인되지 않은 상태에 완료 표현을 사용하지 않습니다.
- 입력창에는 보이는 라벨을 제공합니다. placeholder만으로 필수 정보·형식·오류를 전달하지 않습니다.

## 개선 제안과 남은 검토

다음 항목은 문서화 단계의 제안이며 제품에 적용한 변경이 아닙니다.

- `다시 시도`와 `다시 시도하기` 같은 라벨의 통일 여부를 실제 행동 범위와 함께 검토합니다.
- `미리 번역`과 `일괄 번역`을 사용하는 위치를 검토하고 필요하면 별도 제품 변경으로 정리합니다.
- 새 입력 오류를 추가할 때에는 `aria-invalid`와 설명 연결을 검증합니다. HTML 문서의 입력 오류 샘플은 이 검토 원칙을 보여 주며 앱의 독립 TextField 컴포넌트가 이미 있다는 뜻이 아닙니다.

## 소스와 유지관리

- [토큰](../src/ui/theme/tokens.css), [기본 스타일](../src/ui/theme/base.css), [컴포넌트 스타일](../src/ui/components/components.css)를 디자인 값의 정본으로 사용합니다.
- [SettingsScreen](../src/ui/SettingsScreen.tsx), [ImmersiveReader](../src/ui/ImmersiveReader.tsx), [BatchPanel](../src/ui/BatchPanel.tsx), [WorkScreen](../src/ui/WorkScreen.tsx)를 해당 문구·상태의 근거로 사용합니다.
- HTML은 외부 요청 없이 로컬에서 엽니다. 샘플은 실제 번역·내려받기·삭제·저장을 실행하지 않습니다. 실제 React 컴포넌트 테스트와 Android 실기 검증을 대체하지 않습니다.
- 변경 시 실제 문구, 행동 결과, 취소·반복 조작, 키보드 초점, 좁은 화면, 라이트·다크, 감소된 동작 설정을 확인합니다.
