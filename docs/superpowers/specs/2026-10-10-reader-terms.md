# 리더 용어 강조·바로 추가·편집·삭제 설계 (#265)

## 사용자 요청 (2026-10-10)
- 리더에서 용어를 바로 추가한다.
- 용어집에 있는 단어를 본문에 강조 표시하고, 옵션에서 토글로 켜고 끈다.
- 용어집에 있는 단어를 길게 누르면 편집·삭제를 바로 한다.

## 결정

### 강조할 자리
- 저장본을 읽을 때만 강조한다(실시간 미리보기·실패 문단 제외). 원문·번역 문단이 일대일(`blocks.length === source.paragraphs.length`)일 때만.
- 번역 보기: 그 문단 **원문**에서 `findTermMatches`로 찾은 **확정** 매칭의 용어(origin `auto` 제외)만 고른 뒤, 그 용어의 `target`을 번역 문단에서 찾아 표시한다. 원문에 없는 용어는 번역문에 같은 글자가 있어도 표시하지 않는다(‘공작’ 같은 일반어 오탐 방지). 표기 2글자 미만은 표시하지 않는다. 긴 표기부터 겹치지 않게 잡는다.
- 원문 보기: 확정 매칭 자리를 그대로 표시한다.
- 표시는 `<mark class="nr-term" data-term-source="원문 이름">`. 색은 은은한 밑줄+옅은 배경(독서 배경 3종 모두에서 읽히게).

### 토글
- 보기 설정 시트에 스위치 `용어 강조` + 설명 `용어집에 있는 이름을 본문에 표시해요.` 기본 켜짐.
- 설정 저장 형식 `ReadingSettings.termHighlight?: boolean`(끌 때만 `false` 저장).

### 길게 누르기
- 길게 누른 자리가 강조된 단어면 **용어 시트**, 아니면 지금처럼 **문단 시트**.
- 용어 시트(제목: 원문 이름): `표기 {target}`, 분류·메모가 있으면 표시, 기계 항목이면 `자동 생성`/`정밀스캔` 표시. 버튼 `편집하기`, `삭제하기`.
- 삭제 확인 창: 제목 `‘{source}’ 용어를 지울까요?`, 본문 `다음 번역부터 이 표기를 쓰지 않아요. 이미 번역한 회차는 그대로예요.`, 버튼 `취소`, `지우기`.
- 문단 시트에 추가: `용어 추가하기`(일대일일 때), 그 문단 원문에 확정 매칭된 용어가 있으면 `이 문단의 용어` 아래 용어별 버튼 `{source} · {target}` → 용어 시트.

### 추가·편집 창
- 제목: 추가 `용어 추가하기`, 편집 `용어 편집하기`.
- 원문 문단의 가타카나 덩어리(`ー`·`・` 포함)·한자 덩어리(`々`·`〆`·`ヶ` 포함) 중 2글자 이상을 나온 순서대로 최대 12개 칩으로 보여 준다(추가 모드만). 칩을 누르면 `원문` 칸에 넣는다. 안내 `원문 문단에서 이름을 골라 넣을 수 있어요.`
- 칸: `원문`(필수, 80자), `번역 표기`(필수, 80자), `분류`(선택, 40자), `메모`(선택, 300자). 별칭은 여기서 고치지 않고 그대로 둔다.
- 검사 문구: 비었을 때 `원문과 번역 표기를 입력해 주세요.` / 한 글자·짧은 히라가나 `한 글자나 짧은 히라가나는 용어로 쓸 수 없어요.` / 다른 용어와 이름이 같음(NFKC) `이미 용어집에 있는 이름이에요.`
- 버튼 `취소`, `저장`.
- 저장 규칙: 편집은 `previousSource`로 찾은 항목을 바꾸고 별칭은 유지한다. 기계 항목(`model`·`scan`)을 고치면 origin·evidence를 지워 사람 항목으로 만든다(`auto`는 그대로 사람 항목으로 바꾼다). 추가는 끝에 사람 항목.
- 저장·삭제 후 스낵바: `용어집에 저장했어요. 다음 번역부터 적용돼요.` / `용어를 지웠어요.` 실패하면 `지금은 용어집을 저장하지 못했어요. 번역이 끝난 뒤 다시 시도해 주세요.`
- 잠금: 번역 중(`busy || translationActive`)에는 편집·삭제·추가 버튼을 끄고 `번역 중에는 용어집을 고칠 수 없어요.`

### 데이터 흐름
- `Application`이 `useReaderGlossary`로 작품 용어집을 읽어(`controller.readGuidance`) 리더에 넘기고, 저장은 읽기→수정→`controller.saveGuidance`로 한다. 저장본이 바뀌거나 저장한 뒤 다시 읽는다.
- 컨트롤러 저장 조건(작품 열림·번역 중 아님)은 그대로 쓴다. 실패는 스낵바로 알린다.
