<h1 align="center">JHF Novel Reader</h1>

<p align="center">일본 웹소설을 내 PC의 AI로 번역해서 휴대폰으로 읽는 Android 리더</p>

---

## 이런 앱이에요

‘소설가가 되자(나로우)’에는 한국어로 나오지 않은 작품이 많아요. 웹 번역기로 읽으면 인물 이름이 문단마다 다르게 옮겨지고, 회차를 넘길 때마다 원문 페이지를 다시 번역해야 해요.

JHF Novel Reader는 이 불편을 이렇게 풀어요.

- **회차 전체를 이어서 번역해요.** 앞 문단의 흐름을 이어 받아 한 화를 통째로 옮기고, 번역한 회차는 휴대폰에 저장해서 인터넷 없이도 다시 읽을 수 있어요.
- **이름은 작품마다 한 가지로 고정해요.** 작품별 용어집이 등장인물·지명 표기를 기억하고, 번역할 때마다 같은 표기를 쓰게 해요.
- **번역은 내 PC에서 해요.** 사용자가 가진 PC의 로컬 AI(LM Studio·Ollama·llama.cpp)에 휴대폰이 직접 연결해요. 앱을 위한 별도 서버나 중계 서버가 없어요. 원하면 Google Gemini를 직접 골라 쓸 수도 있어요.

## 주요 기능

**찾기와 읽기**
- 앱 안에서 나로우 사이트를 둘러보며(검색·랭킹 등) 작품을 고르거나, 작품 주소를 붙여 넣어 열어요.
- 회차를 누르면 번역하면서 도착한 문단부터 바로 보여 주고, 끝나면 저장본으로 열어요.
- 여러 회차를 범위나 전체로 **미리 번역**해 둘 수 있어요. 이미 같은 설정으로 번역한 회차는 건너뛰어요.
- 회차 제목과 작품 제목도 한국어로 옮겨요.

**용어집**
- 번역하기 전에 새로 나온 이름을 모아 **용어집을 자동으로 만들어요**.
- 저장한 회차 전체를 다시 살펴 표기를 다듬는 **정밀스캔**이 있어요. 원하면 위키백과·나무위키에서 실존 인물·작품 이름의 한국어 표기를 찾아 근거로 써요.
- 읽는 중에 용어집에 있는 이름을 **강조해서 보여 주고**, 길게 눌러 바로 **고치거나 지울 수** 있어요. 문단을 길게 누르면 원문에서 이름을 골라 **새 용어로 추가**해요.
- 선택 기능으로, 휴대폰 안에서만 도는 작은 판정 모델(약 165MB)을 내려받아 ‘이 이름이 정말 그 용어인지’를 문맥으로 가려요.

**번역 확인**
- 일본어가 남은 문단, 용어집 표기가 빠진 문단을 알려 줘요.
- 번역이 잘못된 문단만 골라 다시 번역할 수 있어요. 이전 번역은 지워지지 않아요.

**읽기 화면**
- 글자 크기, 줄 간격, 독서 배경(기본·세피아·검정), 다크 테마를 고를 수 있어요.
- 원문 보기로 일본어 문단과 번갈아 볼 수 있어요.
- 읽던 위치를 기억해서 이어서 읽어요.

**백업과 복원**
- 서재·저장한 번역·용어집·읽기 위치·설정을 파일 하나로 저장하고, 다른 휴대폰이나 새로 설치한 앱에서 그대로 되살려요.

## 준비물

| 무엇 | 설명 |
|---|---|
| Android 휴대폰 | Android 7 이상, 64비트(arm64) 기기 |
| 번역용 PC | LM Studio, Ollama, llama.cpp 중 하나로 AI 모델을 띄운 PC. 휴대폰과 같은 Wi‑Fi에 있거나 VPN으로 닿아야 해요. |
| 번역 모델 | 일본어→한국어가 되는 모델. Gemma 4 E4B 급에서 실제로 써 봤어요. |
| (선택) Gemini API 키 | PC 없이 쓰고 싶을 때. 사용량에 따라 Google 요금이 생길 수 있어요. |

## 설치

1. [릴리스 페이지](https://github.com/earlydreamer/jhf-novel-reader/releases)에서 최신 `jhf-novel-reader-v….apk`를 내려받아요.
2. 휴대폰에서 파일을 열어 설치해요. 처음이면 ‘출처를 알 수 없는 앱 설치’를 허용하라는 안내가 나와요.

## 처음 쓰기

1. **PC에서 번역 서버를 켜요.** 예: LM Studio에서 모델을 불러오고 서버를 시작해요(기본 포트 1234). 다른 기기에서 접속을 허용하는 설정을 켜 두세요.
2. **앱을 열고 설정 → 번역 서버**에 PC 주소와 포트를 넣어요. `LM Studio 1234`·`Ollama 11434`·`llama.cpp 8080` 버튼으로 포트를 바로 채울 수 있어요.
3. **연결 확인하기**를 누르고, 나오는 모델 목록에서 번역에 쓸 모델을 골라요.
4. 서재로 돌아와 **작품 찾기**에서 읽고 싶은 작품을 열어요.
5. 회차를 누르면 번역이 시작돼요. 다 끝나면 저장본으로 열리고, 다음부터는 바로 읽을 수 있어요.

## 앱 구성

| 화면 | 하는 일 |
|---|---|
| **서재** | 담아 둔 작품과 ‘이어서 읽기’. 진행 중인 미리 번역을 이어서 확인해요. |
| **작품 찾기** | 나로우를 앱 안에서 둘러보고 작품을 서재에 담아요. |
| **작품** | 회차 목록과 저장 상태, 작품 메뉴(용어집 편집, 용어 정밀스캔, 미리 번역, 제목 번역)를 모아 둔 화면이에요. |
| **리더** | 번역을 읽는 화면. 보기 설정, 원문 보기, 번역 정보·확인 결과, 문단 다시 번역, 용어 강조·편집이 있어요. |
| **설정** | 번역 서버와 모델, 번역 방식, 용어 정밀스캔·판정, 화면 테마, 백업. |

연결은 이렇게만 일어나요.

```
휴대폰 ──(원문 읽기)──▶ 나로우
휴대폰 ──(번역 요청)──▶ 내 PC의 AI 서버  (또는 직접 고른 Gemini)
휴대폰 ──(이름만)────▶ 위키백과·나무위키  (정밀스캔에서 켰을 때만)
```

## 개인정보와 데이터

- 번역한 회차, 원문, 용어집, 읽기 위치는 **휴대폰 안의 앱 전용 저장소**에만 있어요.
- 번역 서버 인증값(API 키)은 휴대폰의 **보안 저장소**에 따로 보관해요.
- 외부 사전 조회를 켜도 **용어 이름만** 보내고 회차 본문은 보내지 않아요.
- 판정 모델은 휴대폰 안에서만 돌아요.
- 앱 개발자가 운영하는 서버로 보내는 데이터는 없어요.

## 이전 버전(0.1.x)에서 옮기기

0.1.x는 다른 앱으로 설치돼 있어서 1.0을 깔아도 데이터가 자동으로 넘어오지 않아요.

1. 이전 앱을 0.1.27로 업데이트하고 **설정 → 백업 파일 만들기**로 파일을 저장해요.
2. 1.0을 설치하고 **설정 → 백업에서 복원하기**에서 저장한 파일을 골라요.
3. API 키는 백업에 들어가지 않으니 필요하면 다시 넣고, 판정 모델을 쓰던 분은 설정에서 다시 내려받아요.
4. 새 앱에서 다 확인했다면 이전 앱(JHF Reader)은 지워도 돼요.

## 알아 두세요

- **번역 품질은 모델에 달려 있어요.** 작은 로컬 모델은 문장의 뜻을 잘못 옮기는 경우가 남아 있어요. 앱은 남은 일본어·빠진 표기는 찾아 주지만, 뜻이 맞는지는 판단하지 못해요.
- 공개된 회차만 읽어요. 로그인이나 연령 확인이 필요한 회차는 열지 않아요.
- 번역 결과는 개인적으로 읽기 위한 것이에요. 원문과 번역을 다시 배포하지 말아 주세요.
