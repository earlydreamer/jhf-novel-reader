# narou-reader

나로우 작품을 앱 안에서 찾고, 목차에서 고른 한 화를 통째로 번역한 다음 저장된 한국어 본문을 읽는 Android 리더입니다.

2026-10-07 Linux Hy-MT2 7B의 컨텍스트 구간 번역에서도 Black Shark 2의 전체 입력 처리·저장·오프라인 재열기를 확인했습니다. 큰 중간 누락은 이번 결과에서 확인되지 않았지만 기간·행동·관용구 의미 오류가 남아 [#72](https://github.com/earlydreamer/narou-reader/issues/72)는 열려 있습니다. HTTP 성공이나 문단 수만으로 번역 충실도를 판단하지 않습니다. [#74](https://github.com/earlydreamer/narou-reader/issues/74) 구간 번역, [#75](https://github.com/earlydreamer/narou-reader/issues/75) 범위·전체 회차 번역, [#21](https://github.com/earlydreamer/narou-reader/issues/21) 용어집은 연결된 Draft PR에서 검증 중입니다.

## 첫 사용 흐름

1. 홈의 ‘나로우에서 작품 찾기’에서 검색·랭킹·분류를 이용합니다. 인식한 작품을 열고 원하는 회차를 고릅니다. URL 붙여넣기는 보조 경로입니다.
2. 별도 설정 화면에서 기존 LM Studio·Ollama·llama.cpp의 휴대폰에서 접근 가능한 OpenAI 호환 주소를 입력하고 실제 모델 목록을 확인합니다. 인증은 필요한 서버에서만 입력하며 기기 보안 저장소에 저장합니다.
3. 선택한 회차와 모델을 확인한 뒤 ‘이 화 번역’을 누릅니다. 앱이 모델과 서버 한도를 반영해 원문을 나누고 순서대로 번역합니다. 사용자가 토큰 예산을 계산하거나 입력할 필요는 없습니다.
4. 모든 구간이 완료된 일반 텍스트 결과를 한 화로 합쳐 기기에 저장한 뒤 전용 리더에서 엽니다. 부분 번역은 리더에 표시하지 않습니다. 보정 호출, 자동 재시도, 다른 제공자 전환은 없습니다.
5. 저장본은 현재 모델 설정이나 서버 접속과 독립적으로 다시 읽습니다. 미완료 요청은 자동 재전송하지 않으며 저장 실패는 보존된 결과로 저장만 다시 시도합니다.

작품 목차의 ‘미리 번역하기’에서는 시작·끝 회차를 입력하거나 전체 회차를 선택합니다. 앱이 전체 목차와 대상 회차 수를 확인한 뒤 별도의 시작 버튼으로 순차 번역합니다. 선택한 모델과 저장한 용어집·말투가 같은 기존 완성본은 기본적으로 건너뛰고, 재번역을 직접 선택하면 기존 버전을 보존하며 새 버전을 추가합니다. 회차마다 리더로 자동 이동하지 않으며, 작업이 중단되면 완료본을 유지하고 남은 회차는 명시적으로 재개합니다. 한 작업에는 최대 10,000화를 담을 수 있습니다.

‘작품 용어집·캐릭터 말투’ 편집기에서 표기·별칭·말투를 직접 저장할 수 있습니다. 저장한 항목 중 현재 원문에 등장하는 이름·별칭만 다음 로컬 번역에 전달합니다. 편집이 기존 번역을 바꾸거나 자동 재번역하지 않으며, 미리 확인한 일괄 대상 이후 맥락을 수정했다면 대상을 다시 확인합니다. [기능과 실제 검증](docs/renewal/work-guidance.md).

## 로컬 모델 검증 상태

모델과 서버 한도에 맞춰 입력을 나누더라도 실제 의미 오류는 남을 수 있습니다. 현재 확인한 전송·저장 결과와 번역 품질을 구분합니다.

- **Hy-MT2 7B Q4_K_M:** Linux 서버 context 8,192에서 실제 회차를 14구간으로 처리했습니다. 큰 중간 누락은 확인되지 않았지만 기간·행동·루비 의미 보존은 FAIL입니다. 입력 118–181 tokens의 단독 문제 문단에서도 일부 오류가 남았습니다. [최신 검증](docs/renewal/hy-mt2-segmented-g1-2026-10-07.md).
- **Gemma-4 E4B:** 과거 Linux 실행과 이후 Windows LM Studio에서 장문 처리·저장을 확인했습니다. Windows 전체 대조에서 의미 오류가 남았으므로 일반적인 품질 권장 모델로 확정하지 않습니다. [실제 결과](docs/renewal/blackshark-g2-2026-10-07.md).
- **예산과 완료:** 앱은 모델·서버가 제공하는 한도와 출력·안전 여유를 반영합니다. 입력 추정은 정확한 tokenizer 값이 아니며, 실제 서버 token 사용량과 정상 종료·전체 의미를 함께 확인합니다. 추론 토큰이나 서버 출력 제한도 완료 여부와 별도로 봅니다.

다른 모델과 VRAM 실험의 당시 조건은 [이전 조사](docs/renewal/issue-48-alternative-model-gemma4-2026-10-05.md)에 보존했습니다. 특정 구성의 OOM을 모든 크기·context·기기의 공통 결과로 확대하지 않습니다.

현재 Gemini는 사용자가 직접 선택하는 별도 제공자입니다. 다페이지 목차와 상세 독서 복원을 지원하며, 실제로 전부 확인하지 않은 목차는 일부 범위로 표시합니다. 공개 배포와 원문 이용 권한이 해결되었다는 의미는 아닙니다.

## 구조와 경계

휴대폰이 소스와 기존 로컬 모델 API에 직접 연결합니다. 앱 전용 PC 서버나 운영자 중계 서버는 없습니다. 사이트 탐색은 nonexported AppCompatActivity에 격리하며, 사이트에는 앱의 모델·파일·비밀값 bridge를 제공하지 않습니다. 네이티브 출처 검증과 전송 경계는 리다이렉트에도 적용합니다.

번역 완료본·원문 스냅샷·읽기 위치·시도 메타데이터는 앱 전용 내부 파일에 저장합니다. 인증값은 별도 보안 저장소에만 보관합니다. 웹 브라우저 실행에서는 실제 네트워크·저장 동작을 평문 대체 구현으로 연결하지 않습니다.

기존 청크/작업 기반 실행은 historical 테스트를 위한 legacy 경로로 격리했습니다. 새 bootstrap과 composition은 이를 사용하지 않습니다. 기존 v1 데이터 형식과 검증 코드는 보존하며 데이터 이전은 T6 검증 범위입니다.

## 개발

Node.js ^22.18.0 또는 >=24.11.0을 사용합니다. 고정 의존성과 TypeScript strict/noUncheckedIndexedAccess를 유지합니다.

```sh
npm ci
npm run typecheck
npm run lint
npm run format:check
npm test -- --run
npm run build
npm run android:sync
cd android
./gradlew --no-daemon :app:assembleDebug :app:assembleDebugAndroidTest
cd ..
node tests/e2e/verify-apk.mjs
```

APK 감사는 깨끗한 커밋의 웹/네이티브 출처, 패키지 바이트, 서명, CSP, 로컬 탐색 클래스와 비공개 activity를 확인합니다. 기기에 설치하거나 모델을 실행하지 않습니다. Android SDK 36과 JDK 21이 필요합니다.

## 소스 이용 범위

접근·번역·저장이 허용된 공개 회차만 사용합니다. 로그인·연령·접근 제한을 우회하지 않으며 사용자가 확인한 작품과 회차 범위만 처리합니다. 원문 및 번역 공개 재배포, 회원 동기화, EPUB, 앱 전용 PC 서버는 범위에 포함하지 않습니다.

파서 재사용의 코드 라이선스와 소설 본문의 이용 권한은 별개입니다. LNReader Syosetu 파서의 MIT 고지를 유지하며, 공개 배포 전 최신 사이트 이용 조건과 접근·저장 권한은 별도로 확인해야 합니다.
