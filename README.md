# JHF Novel Reader

<p align="center"><img src="docs/assets/brand-logo.png" alt="JHF Novel Reader" width="160"></p>

나로우(소설가가 되자) 작품을 앱 안에서 찾고, **내 PC의 로컬 LLM**(또는 직접 고른 Gemini)으로 회차를 한국어로 번역해 읽는 Android 리더입니다. 번역한 회차는 기기에 저장되어 서버 없이도 다시 읽을 수 있습니다.

- 안드로이드 패키지: `dev.earlydreamer.jhfreader` · 최소 Android 7
- 받기: [릴리스](https://github.com/earlydreamer/jhf-novel-reader/releases)에서 최신 APK

## 시작하기

1. **번역 서버 준비** — PC에서 LM Studio·Ollama·llama.cpp 중 하나로 OpenAI 호환 서버를 띄웁니다. 휴대폰에서 닿는 주소(같은 Wi-Fi의 LAN 주소나 VPN 주소)여야 합니다.
2. **연결** — 앱의 설정 → 번역 서버에 주소와 포트를 넣고 ‘연결 확인하기’로 모델 목록을 확인한 뒤 모델을 고릅니다. 인증이 필요한 서버만 인증값을 넣으며, 인증값은 기기 보안 저장소에 둡니다.
3. **작품 찾기** — 서재의 ‘작품 찾기’에서 검색·랭킹으로 작품을 열거나, 링크 버튼으로 작품 주소를 붙여 넣습니다.
4. **읽기** — 회차를 누르면 번역하면서 도착한 문단부터 보여 주고, 끝나면 저장본으로 엽니다.

## 주요 기능

- **읽으며 번역 · 미리 번역** — 한 화씩 바로 번역하거나, 범위·전체 회차를 순서대로 미리 번역합니다. 같은 모델·용어집으로 이미 저장한 회차는 건너뜁니다.
- **작품 용어집** — 이름 표기를 작품마다 고정합니다.
  - 번역 전 자동 생성, 저장한 회차 전체를 보는 **정밀스캔**(위키백과·나무위키 조회는 선택).
  - 리더에서 용어 **강조 표시**, 문단을 길게 눌러 **바로 추가**, 강조된 단어를 길게 눌러 **편집·삭제**.
  - 선택 기능: 기기 안에서만 도는 **용어 판정 모델**(EmbeddingGemma 2, 약 165MB)로 애매한 이름을 문맥으로 가립니다.
- **번역 확인** — 가나가 남은 문단·빠진 표기를 표시하고, 실패한 문단이나 고른 문단만 다시 번역합니다.
- **읽기 화면** — 글자 크기·줄 간격·독서 배경(기본·세피아·검정), 다크 테마, 원문 보기, 회차·작품 제목 번역.
- **백업·복원** — 서재·저장한 번역·용어집·읽기 위치·설정을 파일 하나로 저장하고 다른 기기나 새 설치에서 되살립니다. API 키와 판정 모델은 담지 않습니다.

번역 품질은 모델과 서버에 달려 있습니다. 작은 로컬 모델은 문단 단위 의미 오류(기간·행동·관용구)가 남을 수 있어, 앱은 형식·가나·표기만 자동으로 검사하고 의미 판단은 독자에게 맡깁니다.

## 0.1.x에서 옮기기

0.1.x는 패키지가 `app.narou.reader`라서 1.0과 다른 앱으로 설치됩니다.

1. 옛 앱을 0.1.27로 올리고 설정 → **백업 파일 만들기**로 저장합니다.
2. 1.0을 설치하고 설정 → **백업에서 복원하기**로 그 파일을 고릅니다.
3. 필요하면 인증값을 다시 넣고, 용어 판정 모델을 다시 내려받습니다. 확인한 뒤 옛 앱은 지워도 됩니다.

## 구조와 경계

- 휴대폰이 소스 사이트와 사용자의 모델 서버에 **직접** 연결합니다. 앱 전용 서버나 운영자 중계 서버는 없습니다.
- 사이트 탐색은 앱 내부에서 격리된 화면으로 열며, 사이트에는 앱의 모델·파일·비밀값 연결을 제공하지 않습니다. 리다이렉트에도 출처 검사를 적용합니다.
- 원문 스냅샷·번역 저장본·읽기 위치·용어집은 앱 전용 내부 저장소에, 인증값은 보안 저장소에 둡니다.
- 외부 조회(위키백과·나무위키)를 켜면 **용어 이름만** 보내고 회차 본문은 보내지 않습니다. 용어 판정 모델은 기기 안에서만 돕니다.

## 소스 이용 범위

접근·번역·저장이 허용된 공개 회차만 사용합니다. 로그인·연령·접근 제한을 우회하지 않으며 사용자가 고른 작품과 회차만 처리합니다. 원문·번역의 공개 재배포, 회원 동기화, EPUB 내보내기는 범위에 없습니다. 파서 재사용의 코드 라이선스(LNReader Syosetu 파서 MIT 고지 유지)와 소설 본문의 이용 권한은 별개입니다.

## 개발

작업을 시작하기 전에 [프로젝트 작업 컨벤션](CONTRIBUTING.md)을 읽습니다(이슈별 워크트리·브랜치, 한국어 커밋, 이슈·PR 형식, 검증과 정리). 에이전트 진입점은 [AGENTS.md](AGENTS.md)·[CLAUDE.md](CLAUDE.md)입니다.

Node.js ^22.18.0 또는 >=24.11.0, Android SDK 36, JDK 21이 필요합니다.

```sh
npm ci
npm run typecheck
npm run lint
npm run format:check
npm test -- --run
npm run android:sync
cd android
./gradlew --no-daemon :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest
cd ..
node tests/e2e/verify-apk.mjs
```

- 앱 버전은 `package.json`의 `version` 하나로 정하고, versionCode는 `major×10000 + minor×100 + patch`입니다.
- 릴리스 서명·빌드·배포 절차: [docs/release.md](docs/release.md). 키 파일과 비밀번호는 저장소 밖에 둡니다.
- 설계·검증 기록: `docs/` (개발 중 실기기 기록은 `docs/renewal/`, 기능 설계·계획은 `docs/superpowers/`).
